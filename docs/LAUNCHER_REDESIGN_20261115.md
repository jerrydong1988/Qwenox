# 启动器界面重做与性能指标接入

后续正式部署已完成，见 [DEPLOYMENT_UNIFIED_20261115.md](DEPLOYMENT_UNIFIED_20261115.md)。
下面的“尚未替换部署”描述的是界面开发完成时的边界。

本轮按用户确认的“模型启停＋实时性能在首屏，参数放到独立设置页”完成重做。
原先网页启动器没有接入自维护 API 的性能接口；指标采集仍存在于原控制台和 API。
这次复用既有数据来源，不修改引擎计算内核。

## 界面

- 移除二次元人物、壁纸、发光装饰及其静态资源路由；无需额外图片文件。
- 浅色桌面工具布局：左侧模型方案，顶部启停，运行概览、模型设置、推理设置、
  本机设置和日志分开。保留中英文、草稿保存/撤销、文件选择和配置验证。
- 实际运行模型从 API 健康信息读取。编辑下一次启动方案不会改变监控对象或控制台链接。
- 概览显示实时生成/输入吞吐、活动请求、本次服务输出量、60 秒生成曲线、请求进度、
  并发容量和排队数；下方展示历史统计及最近 5 次请求。
- 历史均速、TTFT P50、缓存命中率和推测接受率均明确标注为运行目录累计数据，
  可能包含这里运行过的不同方案。完整请求记录、日期筛选和内存信息仍可通过
  “打开控制台”进入既有控制台查看。

## 指标口径与开销

| 新启动器接口 | 既有数据源 | 口径 |
| --- | --- | --- |
| `/api/metrics` | `/metrics/live` | 每秒读取 API 内存累计计数，按采样时间差计算近期速度；包含全部活动请求 |
| `/api/history` | `/reqstat/summary`、`/reqstat/tail?n=5` | 后端共享 10 秒缓存，避免每个浏览器重复扫描历史文件 |
| `/api/status` 的 `health` | 已有 `/health` 监控响应 | 实际模型名称、并发容量和排队信息；复用既有探活结果 |

Prefill 延续原控制台的按层进度估算，排除缓存命中；Decode 计算已确认输出，
包含思考和工具调用 token。历史平均速度按 token 总量除以耗时总量计算，
推测接受率按接受/提出总数加权，而非简单平均各请求百分比。

服务重启、采样间隔过长或计数回退时丢弃速度差分基线。旧 API 不支持接口、网络错误
或尚未采样时显示“—”及原因，不把缺失数据当作测得的 0。已读历史数据在停止后标为
“上次结果”；首次尚未读取不宣称历史请求为空。页面隐藏时暂停性能轮询。

监控只访问固定的本机 API 路径，不发送引擎 SNAP 查询、不做 GPU 同步。
接口保留跨来源请求限制，响应大小受限。目标地址固定为正在运行服务的地址，
不随待启动配置改变。Linux 生命周期未改变，但本轮新增性能代理仅在 Windows 启用。

## 验证

- 50 项既有启动器/配置检查、18 项指标代理检查、20 项计数语义检查通过。
- 两次独立 Flash HGN 会话各验证 `17 + 25 = 42` 和 1,024 token 的实际生成；
  观察到输入处理、生成阶段、递增输出计数和请求完成后的历史记录。
- 实际浏览器验证方案切换、指标更新、停止后清空实时值、非法参数阻止保存、
  草稿撤销、新方案空名称错误、文件选择、中英文和键盘操作。
- 1383×1243、1024×768、390×844 视口检查，无文档水平溢出和控制台错误；
  宽表和模型方案列表在窄屏内独立横向滚动。
- 独立界面复核发现并修正缺失指标误显示 0、对话框键盘焦点越界两项问题。
  方案和文件选择均使用原生模态 dialog，提供名称、焦点循环和关闭后的焦点恢复。

机器可读记录：[benchmarks/launcher-redesign-20261115.json](benchmarks/launcher-redesign-20261115.json)。
截图、真实采样和测试日志保存在隔离工作树的 `.impeccable/review/` 和 `build/`。
接口缺失截图使用明确标注“测试服务”的本机测试接口；普通性能截图来自真实模型。

## 构建与运行边界

仍使用 `bash build_win.sh web-launcher` 构建；HTML、CSS 和计数脚本全部嵌入可执行文件，
无需 Node.js 运行环境、外部字体或图片。已有 native supervisor、引擎和 API 的契约不变。

本轮只更新源码和隔离预览。两套日常部署的引擎、API、启动器、配置与 HIP DLL 哈希
均与此前记录一致，没有替换。隔离测试模型已停止，保留轻量网页预览供用户查看；
预览中的方案是 8K 测试配置，不是日常 Flash 256K 配置的替代品。
